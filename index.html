About Me

I’m a data platform engineer with 4+ years of experience across data engineering, database operations, and applied AI. I build the systems that move data from the applications that create it to the people and tools that rely on it.

Across my work and projects, I’ve built batch and streaming pipelines, modeled data in cloud warehouses, and supported production databases. I like designing for the next change, whether it’s a new data source, a customer with different access needs, or another engineer taking over the system.

I’m interested in how AI can help people work with data more independently. I’ve built tools that use a customer’s schema and business context to draft SQL, and I’m exploring how that same context can make generated reports easier to check. I want people to be able to use the answer and understand where it came from.

Outside work, I’ve led the Rotaract Club of Hyderabad Corporates, working with volunteers on community projects.

StockStream
Code Demo

Tech stack · Python, Alpaca API, Apache Kafka, Spark Structured Streaming, InfluxDB, Grafana, Docker Compose

I built StockStream to watch live stock prices and trading volume alongside historical trends. A Python producer publishes Alpaca market data to Kafka. Spark Structured Streaming processes the updates and writes them to InfluxDB, where Grafana reads them for its dashboards. Docker Compose runs the pipeline locally.

Tuning Kafka partitioning and consumer offsets brought end-to-end latency below 30 seconds and improved throughput by 25%.


SQL Server to Azure Data Migration
Code

Tech stack · SQL Server, Azure Data Factory, Azure Key Vault, ADLS Gen2, Azure Databricks, PySpark, Delta Lake, Azure Synapse Analytics, Tableau

I built this pipeline to make point-of-sale data from an on-premises SQL Server available for sales and product analysis. Azure Data Factory connects to the database through a self-hosted integration runtime, uses credentials stored in Azure Key Vault, and copies the source tables to Azure Data Lake Storage Gen2 as Parquet files.

In Databricks, PySpark notebooks turn those files into Delta Lake staging and fact tables. Azure Synapse makes the curated data available through serverless SQL views, which Tableau uses for dashboards on product and sales performance.
